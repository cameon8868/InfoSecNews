# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Проект представляет собой учебную версию новостного сайта по кибербезопасности **InfoSecNews**, разработанную с использованием CSS-фреймворка Bootstrap. Сайт имеет кастомную темную тему, стилизованную под современные порталы об информационной безопасности.

## Практическая работа 9

Выполнена главная страница на Bootstrap-сетке.

Реализовано:

- подключение Bootstrap через CDN;
- подключение `css/custom.css`;
- шапка страницы;
- Bootstrap-навигация;
- hero-блок на сетке;
- блок преимуществ;
- сетка популярных товаров (свежих материалов);
- подвал страницы.

## Практическая работа 10 и 11 (Сдача КР №2)

Проект расширен и подготовлен к сдаче контрольной работы.

Созданы и доработаны страницы:

- `index.html` – главная страница;
- `catalog.html` – каталог всех новостей (карточки);
- `product.html` – страница отдельной статьи (характеристики, аккордеон);
- `order.html` – форма подписки на новости.

Реализовано:

- единая Bootstrap-навигация на всех страницах (с выпадающим меню);
- использование компонента `card` для отображения новостей;
- метки статусов через `badge` (Уязвимость, Инцидент и т.д.);
- кнопки действий `btn` (primary, outline-primary);
- информационные сообщения `alert`;
- модальное окно `modal` для быстрой подписки;
- формы с классами `form-control`, `form-select`, `input-group`, `form-check`;
- дополнительный компонент `accordion` на странице статьи;
- «хлебные крошки» `breadcrumb`;
- адаптивные таблицы `table-responsive`.

## Самостоятельные доработки

- Разработана кастомная темная тема с использованием CSS-переменных (`--header-bg`, `--surface`, `--border` и др.);
- Выполнено стилевое переопределение стандартных компонентов Bootstrap (карточки, формы, таблицы, модальные окна, аккордеон) под общую темную палитру;
- Предметная область адаптирована под новостной инфобез-портал (вместо магазина товаров — новости и статьи).

## Подключение Bootstrap

В проекте Bootstrap подключён через CDN.

Используются:

- `bootstrap@5.3.3/dist/css/bootstrap.min.css`;
- `bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js`.

Собственный файл `css/custom.css` подключён после Bootstrap для переопределения стилей.

## Используемые технологии

- HTML5;
- Bootstrap 5.3.3;
- CSS3 (Custom Properties);
- Git;
- GitHub.
